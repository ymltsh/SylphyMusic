# 界面调整 · 2026-10-27

参考用户提供的 [界面讨论](https://chatgpt.com/s/t_6ae0386123c48191878f426379c934ec)，本轮在现有 Flutter 工程中调整 UI。

## 已实现

- 首页、音乐库、歌单、我的四项导航；宽屏侧栏；设置位于右上角，音乐源管理移入设置。
- 首次使用独立引导：连接现有支持的远程来源或导入本地音乐，沿用连接验证、同步进度和错误提示；支持跳过并记住选择，已有来源断网不重新引导。
- 首页清爽 Material 3 卡片、最近播放 / 收藏 / 全部音乐 / 下载快捷入口、最多 8 张专辑和继续播放入口。当前专辑区按名称取前 8 张，不表示新增时间或算法推荐。
- 歌曲、专辑、艺术家合并在音乐库内部，使用可横向滚动的圆角矩形 `ChoiceChip` 筛选栏（圆角 8 dp）切换；三个分类都位于播放全部操作行下方，距左侧 16 dp 对齐。选中项使用主题主色，未选中项使用主题 Surface 容器色。保留来源筛选、排序与曲目操作；歌曲连续滚动，底层仍分批 SQL 查询。右上角搜索按钮进入独立搜索页，搜索页继续使用自己的分类控件和来源筛选。
- 单行圆角迷你播放器、队列和缓冲 / 播放进度；全屏、歌词页和折叠迷你播放器共用同一封面样式，完整歌词统一打开独立页面，不再使用左右分页或宽屏内嵌歌词。
- 本地保存浅色 / 深色 / 跟随系统、默认封面 / 唱片、封面模糊背景（默认关闭）及默认关闭的实验性磨砂选项。
- 最近播放记录实际开始播放的曲目，最多保留 50 首独立身份；恢复暂停队列不计入记录，不把队列伪装为播放历史。

## 保留范围

来源协议、音频控制、缓存完整性和云歌单状态机沿用现有实现。参考讨论中的 Jellyfin、SMB、独立文件夹层级浏览、智能歌单、应用图标、语言选择、唱片旋转和封面取色主题未在本轮新增。播放页默认跟随应用浅色 / 深色主题；可选封面模糊背景，默认主色为 #5094B2，并支持手动选择主题颜色。

## 搜索与滚动调整

主界面原同步按钮改为搜索；同步所有来源位于「设置 → 音乐源管理」。音乐库不再放搜索框，独立搜索页输入使用 250 ms 防抖，提交立即搜索，支持清空和无结果提示。

歌曲列表（包括搜索结果、专辑 / 艺术家内歌曲和添加歌单时的选曲列表）移除上一页 / 下一页及页码。ListView 按可见行请求每批 100 条数据，滚动缓存最多六批；离开缓存区域后可重新按需读取，快速跳转不会累积完整曲库元数据。切换查询、来源、排序或索引版本后清空缓存，旧请求完成时不会写入新查询的结果。专辑 / 艺术家的聚合列表也使用连续滚动。

`integration_test/large_library_test.dart` 验证五万首库跨批次滚动、末尾 / 返回顶部及请求中切换搜索。`integration_test/ui_refresh_test.dart` 验证新搜索入口、清空 / 无结果、音乐库无搜索框以及同步按钮只在音乐源页。包内内容以最近一次构建记录为准。

歌曲列表的播放操作行保留播放图标，只显示数量数字（不再显示「播放全部」或「首」）；音乐库歌曲 / 专辑 / 艺术家三个视图的来源过滤、排序与升降序按钮位于该行右侧，移除分类下方原按钮行。专辑 / 艺术家也显示播放图标和对应专辑数 / 艺术家数；播放全部加载当前来源与筛选范围内的所有歌曲身份，不只播放分组代表曲目。

2026-10-27 后续调整：默认主色改为 #5094B2，支持预设 / 自定义主色与仅四个一级页面使用的背景图；一级页面标题按当前页面显示，首页名称区分英文系统。实现和范围见 [外观说明](APPEARANCE.md)。

## 2026-10-27 沉浸播放与歌词

播放页跟随应用浅色 / 深色主题，使用主题色板或封面取色和自适应遮罩；默认不叠封面模糊，只有开启「封面模糊背景」后才在封面背景下叠加柔化封面。系统栏同步当前明暗。当前手机与宽屏都使用同一套自由画布布局；完整歌词只打开一个独立页面，不再有双圆点或左右分页，但播放页内容支持从右向左滑动进入该页面。保留全局方形封面 / 唱片选择，将音质参数收进「更多 → 音质信息」。全屏使用唯一一套细进度条、时间、五个主控制及队列入口，播放按钮放大；进度条上方提供睡眠定时、歌词页、收藏和更多。

歌词按实际文本高度排版，长句完整换行；同时间戳的原文与译文合并显示，空时间行显示间奏标记。当前行在可用区域约 43% 的阅读焦点高亮，手动拖动 / 滚轮浏览后停止跟随，点击「回到当前」恢复；点击歌词仍可跳转播放时间。支持小 / 标准 / 大字号、系统字体缩放及减少动画设置，无时间轴的文本提供完整可选择阅读。歌词页顶部显示小封面与曲目信息，底部与播放页共享播放控制。保留加载、无歌词和错误重试提示。

本次背景使用封面自身色彩；强调色沿用用户主题。睡眠定时现已接入倒计时暂停；唱片旋转作为全局外观设置补充。

## 可视化播放页编辑

播放页「更多 → 编辑播放页」可选择沉浸封面 / 歌词优先模板，在完整播放页画布上添加、拖动缩放组件，使用 9 / 16 宫格辅助线与吸附、调整样式，支持撤销重做、保存模板与 JSON 导入导出。编辑预览不操作播放，独立于布局组件的快捷行保留恢复入口。组件、版本校验、适配规则和当前范围见 [编辑器说明](PLAYER_LAYOUT_EDITOR.md)。

## 合并播放模式

随机与循环现在共用一个按钮，依次切换「列表循环 → 单曲循环 → 随机播放 → 列表循环」，当前图标和 Tooltip 同步显示模式。迷你播放器、默认全屏页、自定义布局共用 PlaybackModeButton；编辑预览仍不可触发播放操作。切换不改变当前歌曲、播放进度或暂停状态，随机模式使用整队列循环，退出随机后恢复队列自然顺序。旧顺序模式归并为列表循环，旧随机 + 单曲循环组合按单曲循环恢复，曲目、进度和历史保留。

## 播放控制与歌词切换补充

播放 / 暂停支持圆角矩形，自定义控制组件可调圆角与宽度；播放列表按钮并入主控制区。唱片形状与旋转是全局外观设置，编辑预览、播放页和迷你播放器一致，暂停、隐藏和减少动画时停止旋转。完整歌词统一由播放页右向左滑动或点击歌词预览打开独立页面，不再有自定义布局专用 PageView；播放页内的迷你歌词区不显示右下角缩放按钮，尺寸统一在编辑器内调整。编辑器中的相关设置见 [播放器布局说明](PLAYER_LAYOUT_EDITOR.md)。


## 播放页视觉收敛与控制尺寸

播放页顶栏已移除；睡眠定时、歌词页、收藏和更多位于进度条上方。更多仅保留音质信息与编辑播放页，其余外观设置放在编辑器对应组件内。默认页与自定义页共用主题底色、可选封面模糊、主题强调色、进度和播放控件；手机歌词页统一小封面与歌曲信息，不常驻跟随状态和字号工具栏。定时歌词隐藏桌面自动滚动条，仍可滚轮 / 拖动浏览并回到当前。

同时间戳的第一行作为主句，后续行使用较小字号与较低字重；仅按顺序区分层级，不声称自动识别译文语言。测量与渲染使用同一富文本样式，保留换行、系统字体缩放和点击 Seek。歌词焦点上移，避免首句上方过量留白。

新模板缩短歌曲信息间距；v1 自定义竖屏坐标通过迁移保留。宽屏使用同一自由画布的独立宽屏坐标，不再把竖屏标题拉到歌词栏。控制组件支持按钮间距与主播放按钮独立宽高，详情见 [布局编辑器](PLAYER_LAYOUT_EDITOR.md)。

## 迷你播放器折叠

迷你播放器改为悬浮在页面内容之上，去掉底部整条背景白边；空白区域长按收起为右下角悬浮按钮，按钮使用与播放页 / 歌词页共用的 `PlayerCover`，唱片模式显示黑胶，方形模式显示圆角封面；唱片模式下播放时自动旋转并在暂停时保持角度；点击按钮在 260 ms 内自然展开，减少动画设置下直接切换。收起状态只影响当前会话，不写入设置；播放控件区域的长按不会触发收起。

## 自由画布、歌词预览与封面取色

播放页不再划分封面、歌词信息、播放控制三个区块，也不再提供区块顺序。系统默认页和自定义页共用一套自由画布；编辑器载入当前实际页面，用 9 宫格（3×3）或 16 宫格（4×4）辅助摆放，拖动、缩放和吸附都在整页范围内进行。旧的 v1 区域布局会在读取时迁移为全画布坐标。

封面下方的歌词预览按可用高度显示最多五句当前歌词，只显示时间戳的主句，每句长文本最多自动换为两行；按测量高度减少相邻句数，优先显示当前句；它是播放页内的迷你歌词控件，尺寸在编辑器中调整。点击预览或右向左滑动打开唯一的完整歌词页，原文 / 译文层级、跟随、滚动、点击 Seek、字号和重试都在该页处理。完整歌词字号 20 / 24 / 28 可在设置或歌词页顶部切换；迷你歌词字号 16 / 20 / 24 可单独在设置或编辑器「歌词预览」中切换。两者独立持久化，不写入模板的逐元素字号。

播放页按钮、进度条、模式图标和歌词高亮使用当前封面提取的 Material 3 色板；取色失败或没有封面时回退到主题色。删除页面分页和圆点；手机播放页仍可向下拖动退出，减少动画设置下不播放入场和回弹动画。

外观设置包含「纯色背景」，未设置背景图时默认启用：浅色模式使用白色、深色模式使用黑色，优先于一级页面自定义背景图；它同时作为播放页无封面模糊时的基础底色。升级时已有背景图继续显示，重新选择背景图会关闭纯色模式，原受管图片按既有清理规则保留或替换。一级页面的标题栏和底部导航随纯色背景透明化。

`integration_test/ui_refresh_test.dart` 同时覆盖音乐库 3 枚圆角矩形筛选、默认歌曲选中和切换专辑选中。`test/appearance_test.dart` 覆盖完整 / 迷你歌词字号、纯色背景及黑白切换；`test/lyrics_preview_test.dart` 覆盖预览行数上限、普通文本和不拼接译文；`test/player_layout_test.dart` 覆盖 v1 迁移、9 / 16 宫格吸附和封面正方形边界；`test/cover_palette_test.dart` 覆盖封面取色；`integration_test/ui_refresh_test.dart` 覆盖统一完整歌词页、歌词预览与重试、同一歌词页返回、右向左滑动进入歌词、迷你歌词无缩放按钮、编辑器内字号调整、浅色播放页 / 白底纯色、浅色封面模糊、深色切换、封面状态、主播放键前景和下滑退出，在 Windows 原生集成测试通过。


## 播放页菜单精简

播放页「更多」只保留「音质信息」「编辑播放页」。封面 / 唱片与旋转迁入编辑器「专辑封面」，迷你歌词字号迁入「歌词预览」，封面模糊开关迁入「页面」，使用系统默认布局迁入「布局操作」。这些全局外观设置自动保存并刷新预览；组件位置和模板仍由保存并应用提交。移除查看完整歌词、各档完整歌词字号和导入歌词菜单项；完整歌词通过点击歌词区或左滑打开，字号在完整歌词页内调整。


## 播放页快捷操作与睡眠定时

播放页不再预留顶栏的 56 dp，高度与编辑器预览同步。进度条上方四个图标依次为睡眠定时、歌词页、收藏、更多；下滑收起、左滑打开歌词仍可用。睡眠定时提供 15 / 30 / 45 / 60 / 90 分钟和取消，在应用会话内跨页面保持，替换定时会取消旧任务，到期暂停当前播放；应用退出时取消，不跨进程持久化。应用恢复前台时复核截止时间，Android 后台精确定时尚未在实机验收。


## 音乐库分类切换稳定性

播放数量操作行在加载、成功和失败状态使用同一布局，分类 / 来源查询期间保留播放图标、来源与排序入口，数量显示「—」且暂时禁用播放；结果返回后仅更新数字和列表，空结果显示 0。圆角筛选栏位置不随异步查询状态改变，快速连续切换也不会上下抽动。
