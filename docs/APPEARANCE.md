# 自定义外观

## 用户入口

设置 → 外观与体验：

- 外观模式：浅色、深色或跟随系统。
- 主题颜色：默认 `#5094B2`，提供预设色与 6 位 HEX 输入，支持恢复默认。选定色为实际主色，其余 Material 3 颜色从该色生成，按钮前景根据主色亮度选择。
- 纯色背景：未设置背景图时默认启用，浅色模式使用纯白、深色模式使用主题炭灰底色（`#0F1417`），优先于一级页面自定义背景图；播放页在封面模糊关闭时也以白底或主题 Surface 为默认底色。重新选择背景图会自动关闭纯色模式。
- 封面模糊背景：播放页可选的封面模糊层，默认关闭。可在设置或播放页编辑器的「页面」中开启；开启后仅当播放页布局背景为「封面模糊」时叠加，关闭时播放页、歌词页和编辑器预览都跟随浅色 / 深色主题与纯色背景。
- 完整歌词字号：20 / 24 / 28 三档，作用于唯一完整歌词页；不再写入自定义布局的逐元素字号。
- 歌词页面取色：专辑取色（默认）、跟随系统黑 / 白或固定颜色，固定模式可单独选择高亮歌词颜色。
- Android 桌面歌词：默认关闭，设置 → 歌词设置中主动开启并授予悬浮窗权限后显示；支持跟随系统与固定颜色，不支持专辑取色。字号可在 12–40 间调节，默认 20，独立于播放页歌词字号。开关、颜色与字号保存在既有 settings 表。
- 桌面歌词背景与关闭按钮：显示或操作后静置约 2.5 秒，再用 350 毫秒淡出，仅保留歌词；触摸歌词恢复操作区域，可拖动或点击 × 关闭。歌词换行不重置隐藏计时，颜色和字号改变会短暂显示操作区域。
- 迷你歌词字号：16 / 20 / 24 三档，默认标准 20，只作用于播放页迷你歌词区和布局编辑器预览；可在设置或播放页编辑器的「歌词预览」中调整。
- 唱片播放样式与圆形封面旋转：全局作用于系统默认布局、自定义布局、歌词页头图和折叠迷你播放器；编辑预览使用同一形状。播放页编辑器的「专辑封面」与设置共用这两个偏好。
- 播放器外观 → 播放器控制：选择每次启动主界面时的默认样式（横条或 FAB 悬浮按钮），默认横条，保存为 `ui_player_fab`。长按横条折叠和点击 FAB 展开仅改变本次会话，不改写启动默认值；在设置中修改默认值时立即应用新选择。
- 自定义背景图：选择 JPG / PNG / WebP，保持比例、居中自适应铺满；通过背景可见度调整视觉强度，也可移除。

一级页面的自定义背景图只在首页、音乐库、歌单、我的显示；其他地方不显示自定义图片。纯色背景同时为一级页面和播放页提供基础底色，播放页局部主题、封面取色和可选封面模糊仍由播放页自己的背景规则处理。

一级页面的标题：首页仅显示应用名，系统语言为英文时是 `Sylphy Music`，其他语言为「风灵音乐」；音乐库、歌单、我的显示对应页面名，不再显示应用名副标题。运行中切换系统语言会刷新首页名称。Android 启动器使用同一套语言规则：默认资源为 `Sylphy Music`，`values-zh` 为「风灵音乐」。

深色主题使用分层炭灰 Surface，用户主色继续用于强调元素；播放页共用全局基础主题。底部导航栏内容高度随字体缩放与屏幕高度在 68–104 逻辑像素间调整，仍由 NavigationBar 处理系统底部安全区；深色导航栏和折叠 FAB 使用相应 Surface 层级。

歌曲、专辑和艺术家列表统一使用连续滚动，取消分页栏。每次仍由 SQLite 按可见位置加载 100 行，最多缓存六批；不会因移除分页一次加载全库元数据。

## 存储与实现

`Appearance` 通过已有 settings 表持久化主题色、背景受管文件名、可见度、纯色背景、封面模糊开关、完整歌词字号、迷你歌词字号、全局封面形状与旋转，不升级数据库 schema。图片在服务层读取、验证及按比例解码，最长边限制到 2048 像素，编码为应用数据目录中的 PNG。导入源文件上限 40 MB；先写临时文件再原子改名，设置成功后替换旧图片。取消或解码失败保留原背景；移除仅删除受管副本，不删除用户原始图片。图片不放入源码、应用资源或安装包。

受管文件名限制在固定命名空间，避免从设置值访问任意路径。导入 / 替换 / 清理串行执行，`SylphyApp.disposeAsync()` 等待图片任务完成后再关闭数据库。文件选择器取消或关闭后不继续写入已释放的应用。

`AppBackground` 只包围 SylphyShell 的一级 Scaffold；播放页使用 `PlayerBackdrop`，按当前 `Theme.brightness` 使用浅 / 深色调色板，并以纯色背景或主题 Surface 为基础。`sylphyTheme` 统一生成主题，`AppSystemBars` 独立管理透明系统栏和图标明暗。主题颜色和深浅色对所有页面生效，自定义背景图的范围独立受控。

## 验证

`test/appearance_test.dart` 覆盖默认色与实际主色一致、偏好恢复、背景副本独立于原文件、坏图替换保留旧图、长边限制 / 比例和串行替换 / 清理，以及完整 / 迷你歌词字号、纯色背景、封面模糊默认关闭和黑白切换。`test/cover_palette_test.dart` 覆盖封面色板在浅色 / 深色下的生成。播放页布局与全局唱片状态由 `test/player_layout_test.dart` 和原生 UI 测试覆盖。

Android 原生系统栏测试额外验证颜色对话框应用和恢复默认、自定义背景出现于主页、设置 / 搜索 / 播放路由不出现背景、图片设置恢复，以及键盘和手势安全区。Windows UI 测试验证中英文系统下的首页名称、一级页标题和小屏布局。大库测试以五万首歌曲及超过 100 组专辑 / 艺术家验证连续滚动。实际执行结果见 [PROGRESS](PROGRESS.md)。
