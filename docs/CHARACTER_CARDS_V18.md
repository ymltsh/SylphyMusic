# 音乐笔友角色卡

角色卡使用稳定 `card_id` 保存角色名称、System 与 User 提示词。聊天、记忆和来信按角色身份隔离，修改提示词不改变角色 ID。数据库版本为 v19。

## 管理与编辑

- 每张角色卡直接提供“编辑提示词与角色”按钮，在同一窗口修改名称、System、User 并一次保存，支持现有长提示词限制。新建角色也在同一窗口配置设定。
- 默认角色、自定义角色和彩蛋角色均可编辑和删除。编辑彩蛋角色修改的是本地卡片，不改动 `assets/penpal/venti.json` 与 `sylphiette.json` 原始素材；编辑后的卡片标记为自定义角色。
- 更新当前角色时，角色内容和 API 设置的 Prompt 镜像在同一事务中保存，再通知推荐配置变更；已有聊天与记忆继续属于原角色 ID。
- 删除角色会删除其聊天与记忆，已有来信保留原作者 ID。删除当前角色时，在同一事务中选用另一张角色卡；删除最后一张卡会创建使用新 ID 的默认笔友，避免旧记忆混入新角色。
- 导入、导出 JSON 包含 `name/system/user`，导入分配新的角色 ID，不覆盖现有角色；不导出聊天、记忆、账号与密钥。

## 彩蛋与隐私

温迪和希露菲初始隐藏，只在图标彩蛋主动应用后加入列表。升级前已应用完整原卡时可通过精确匹配承接已有选择；原始角色素材保持不变。删除彩蛋角色后可从图标彩蛋重新发现。

笔友支持独立自定义头像：点击角色列表头像或在菜单选择“更换头像”，可选择 PNG/JPEG/WebP；支持恢复默认头像。头像显示于角色列表和聊天页头部，本地保存，不发送给模型，不进入角色 JSON 导出。图片读取上限 8 MiB，解码后最长边缩至 512 像素，保存为应用管理目录 `penpal_avatars/` 中的 PNG 副本；更换、清除和删除角色只移除受管副本，用户原图保留。使用原 `art_path` 列保存头像相对路径，不新增数据库迁移；绘画提示词列不再读写，也不提供 AI 绘画功能。图片操作串行执行，退出时等待完成后再关闭数据库。

每张卡分别管理记忆开关与人格补充，清空只影响当前角色。v19 升级直接删除空角色 ID 的未归属旧记忆，不再查询或展示。旧来信与聊天不猜测角色归属。角色切换时沿用配置版本与在途响应校验，避免把旧角色的响应提交给新角色。

## 交付范围

源码补丁备份位于 `.private/character-cards-v18-before/`。数据库从 v16/v18 前向升级至 v19，旧应用不能直接打开新版本数据库。编译不代表数据库迁移、模型或设备功能已验收。
