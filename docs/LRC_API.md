# LrcApi 在线歌词补充

入口为「设置 → API 设置」。功能默认关闭，可修改接口地址及可选鉴权密钥。开启后，仅当手动导入、本地歌词、WebDAV 内嵌 / 旁置歌词或服务器歌词均未提供可用内容时，尝试在线补充；原来源请求报错时也会尝试。若补充仍不可用，保留原来源的错误或既有缓存回退。

请求向配置的接口发送 title、artist、album 中非空的字段。设置界面在开启入口说明此数据用途；不会发送歌曲文件、音源地址或音源账号凭据。结果依赖服务端匹配，不更换音频或曲目身份。

默认地址为 https://api.lrc.cx/lyrics。自部署可填写 HTTP(S) 根地址或路径前缀，自动追加 /lyrics；保留明确的 /lyrics 或 /jsonapi 端点。URL 不接受用户凭据、查询参数或片段。支持纯文本 LRC 与 JSON 歌词结果。密钥仅保存于系统 AuthVault，通过 Authorization 请求头发送；配置密钥后只允许 HTTPS 或本机回环 HTTP。请求拒绝重定向，响应上限 1 MiB，连接响应与正文读取各有 12 秒超时。

补充结果按 TrackRef 与资源版本进入现有歌词缓存，自动缓存有效期六小时；不覆盖手动导入。修改接口或关闭补充会取消在线请求，已缓存内容仍遵循现有缓存有效期 / 刷新规则。来源停用取消该来源的在线补充，退出取消全部请求并等待歌词读取结束。请求失败不写入新的有效缓存。

验证入口：test/lrc_api_test.dart、test/api_settings_test.dart 与 test/lyrics_cache_test.dart，覆盖 URL、元数据编码、鉴权、JSON、响应限制、取消、设置恢复、优先级、本地补充、缓存复用及原错误保留。测试使用合成数据与本机服务器，不依赖公共接口在线可用性。
