# 与笔友聊天

原来的“回一句”已升级为连续聊天。每日精选和存档信件的按钮 / 更多菜单都能进入，与当前配置的笔友角色互动。可以讨论选曲，也可以单纯闲聊；顶部的信件标签可取消，让这一轮不再附带原信内容。

对话按角色人格和信件分别保存，历史分批加载。旧版本已保存的回复在升级到 SQLite v16 时保留为用户历史，不凭空补写笔友回答。修改角色 System 提示词会切到新的角色会话，不混用别的角色发言。

“记住聊天，帮助后续选曲和写信”控制本轮新消息是否保存。全局记忆关闭时不可保存；关闭回忆时不加载、发送旧对话，但当前页面的临时上下文仍可继续交流。开启保存后，只在本轮成功时原子保存用户消息和回复，并把用户原话写入可删除的个性化观点。失败不自动重试，不重复保存；离开页面可取消未完成请求。聊天仍使用已配置的模型、接口和密钥，不另建账号。

观点会作为后续新推荐的选曲和写信参考；不会把角色回答、推测或闲聊自动解释成用户情绪，也不会自动改变音乐库、收藏或播放队列。当前已生成的来信保持原样，想立即使用新观点可手动换一批。

聊天内容会发送给用户配置的模型。对话和观点可从聊天页 / 记忆页清理；清空对话同时删除该对话的个性化观点，清空全部记忆或清理来信同步删除相应聊天。聊天内容不进入诊断日志。真实模型兼容性、数据库升级与设备交互需由用户验收。
