# Emby 真实测试环境接入说明

项目按完整首版目标开发。真实 Emby 联调用于验证适配并修复代码，而不是延期缓存功能。

## 请准备（尽量不含私密信息）

- 能从开发/测试设备访问的 Emby Base URL（可包含反向代理子路径）；若仅局域网可达，必须在相同网络或授权的 VPN 环境中运行测试。
- Emby 版本和一组有代表性的媒体：MP3、FLAC、不同采样率、含封面/歌词、允许 Seek 的曲目。
- 专用可撤销测试账号；至少一个明确允许写入/删除的**测试歌单**，如可能再提供只读歌单。
- 是否允许对专用测试歌单执行新建、添加、移除、重排和删除操作；默认只读。

**不要向公开仓库、Issue、诊断日志提交真实密码/Token。** 在本地运行的 App 登录界面输入账户凭据，交由 `flutter_secure_storage` 管理。任何测试必须只操作获准测试数据。

## 联调验收顺序

1. 连接与登录，正确识别服务器/账号与 TLS/HTTP 处理。
2. 分页扫描歌曲、专辑、艺术家、歌词/封面资源；验证多账号隔离。
3. 通过 BR1 向 libmpv 提供原始音频；播放、Seek/Range、中断重试。
4. 统一完整音频 READY 缓存、P2、LRU、整首文件校验；缓存任务并发与恢复。
5. 专用测试歌单在线 CRUD、离线编辑、双设备修改、冲突提示、只读权限。
6. Android/Windows/Linux 对照测试、记录差异并修复。
