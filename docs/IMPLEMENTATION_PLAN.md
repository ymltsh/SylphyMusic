# 风灵音乐（Sylphy Music）— 完整首版实施计划 v1.0

- 适用规格：`music_player_spec_v3.8.md`
- 决策状态：**完整正式版一次性交付已确认的首版范围**（IMP-001）；禁止拿 M0 演示骨架、单功能 PoC 或内部 Debug 包充当首个正式版。
- 当前实际状态：主工程已有部分源代码，但尚未在这里运行 Flutter/Dart 编译、三端实机测试；不能称为已完成或已稳定。
- 实施模式：同一个主项目全模块开发，内部工作包按风险并行推进 + 每次集成测试 + 全部验收后才发布首个正式版。

## 1. 交付定义

**首个正式版**包含：三端 Flutter + Material 3、真实 Emby/OpenSubsonic/本地音源、统一音乐库四分类/搜索/排序/曲目黑名单、来源与权限隔离、完整本地/云端歌单和收藏、离线编辑与冲突处理、音频后台播放和桌面媒体控制、歌词封面、播放状态恢复、完整整曲缓存与缓存歌单、P2/Range/Seek/LRU/空间管理，以及开源仓库和可复现构建流程。

**不纳入**：服务器转码、独立离线下载、自动歌曲去重、EQ、Crossfade、额外音源协议、跨设备播放状态同步等既有非首版范围。

## 3. 重点工程风险与应对

1. **BR1 回环代理可行性**：必须在 Android 后台与 Windows/Linux 验证会话鉴权、音频头与 Range、启动/Seek 延迟、断开/重连；失败需保存数据并评审桥接替代实现，不能静默改变“整曲缓存”设计。
2. **Emby 服务端差异**：真实账户/版本/媒体库逐项核对音频直流、分页索引、封面、歌单写入与权限；远端删除只有在确认安全 API 后才能开放。
3. **整曲缓存一致性**：原始音频仅 READY 持久化；中断 TEMP 删除，重启歌曲从头获取；Q1 恢复批量任务元数据、绝不续接半首；单账户资源版本隔离；文件/SQLite 崩溃对账。
4. **Android 后台**：音频播放前台服务与用户主动缓存任务是不同生命周期；必须使用系统允许的调度方案，通知、权限与设备省电策略都测试；不夸大强停后能力。
5. **双向云歌单**：以真实测试歌单测试在线 CRUD、离线更改、不同设备并发、只读与冲突暂停写回；留存未同步本地修改。
6. **跨平台支持**：Android 优先稳定，Windows 完整可用，Linux 兼容性经真实设备测试；差异在发布前明确处理。

## 4. Emby 测试连接准备

| 信息 | 用途 | 处理原则 |
|---|---|---|
| Emby 基础 URL（可能含子路径） | 连接与反代兼容性 | 仅在授权测试环境使用；HTTP 和 HTTPS 均按现有规格支持 |
| Emby 版本 / API 响应样本 | 核对协议差异 | 可先提供脱敏数据，不暴露隐私歌曲列表 |
| 测试账号 | 登录、最小权限验证 | 单独创建可撤销账号，密码/Token 不加入仓库 |
| 可操作测试歌单 | 验证新建/增删/重排/同步 | 仅在明确批准的测试歌单中写入，不触碰重要歌单 |
| 原始媒体样本 | MP3、FLAC、高解析、歌词/封面、Seek/Range | 样本不需要包含私人或有版权限制的媒体内容 |
| 网络条件 | 局域网、公网、反代、VPN | 内网连接须在能实际连通的测试设备上进行 |

**不要求在聊天中发送密码或 Token**。真实凭据应该通过本地应用安全输入或者用户许可的私密测试方式提供。若只有 LAN 地址，本会话环境可能无法直接访问，需开发机器/测试机完成真实联调。
