# 播放页布局编辑器（v4）

## 核心原则

播放页仍是一张全画布：封面、标题、歌手、歌词预览、进度条、控制和快捷操作都是同等的 `PlayerElement`。组件可以拖动、缩放、隐藏、删除，并具有独立的竖屏 `frame` 和宽屏 `wideFrame`。不存在专门的“沉浸播放页”、隐藏背景合成通道或第二套歌词系统。

## 专辑封面的三个样式

编辑器选中「专辑封面」后可在下列样式中三选一：

- **圆角封面** `rounded`：方形尺寸约束，可调圆角。
- **黑胶唱片** `vinyl`：方形尺寸约束，独立的逐组件旋转开关。
- **沉浸封面** `immersive`：同一种普通封面组件，切换到该样式时，将其竖屏和宽屏初始 `frame` 设为顶部对齐、宽度 100%、高度 50%，默认向下渐隐；之后用户可以自由改变 X/Y、宽度、高度。图片在矩形范围内 `BoxFit.cover`，ShaderMask 使用 `BlendMode.dstIn` 在选定边缘逐渐透明，露出下一图层；可选渐隐方向（左/右/上/下）和渐隐起点。播放画布延伸到透明状态栏下，保留侧边和底部安全区，编辑器使用相同画布尺寸。

组件本身不修改 `PlayerBackdrop`，不全屏截取歌词，不接管图层顺序。`PlayerLayoutRenderer` 仍按 `elements` 顺序叠放，其他组件可以显示在沉浸封面之上或之下。编辑器与播放页共用 `PlayerWidgetRegistry`。

选中「播放控制」后，播放键颜色可选择「透明」：移除播放 / 暂停键的填充背景，图标使用主题前景色，保留按钮尺寸、点击区域与交互反馈。保存布局后可恢复此选项。完整歌词页的播放键跟随当前播放布局中第一个可见播放控制组件的颜色（含透明）和圆角；未配置可见播放控制时使用主题默认样式。

迷你播放器横条和完整歌词页顶部的小缩略图使用独立的圆角封面；主界面与子页面的迷你播放器悬浮按钮始终使用圆形黑胶唱片，播放时旋转、暂停时保持角度。它们均不继承播放页封面组件的样式或旋转设置。

## 配置与版本

本次为主动破坏性升级：

- 布局 JSON 版本由 v3 提升为 **v4**，不再读取 v1/v2/v3，也不提供导入迁移。
- 持久化设置键变为 `player_layouts_v2`，容器版本为 **3**。旧的 `player_layouts_v1` 留在数据库中，但不再读取或修改。升级后用户需重新布置播放页。
- 全局 `Appearance.disc`、`Appearance.discRotation`、`ui_disc` 与 `ui_disc_rotation` 不再参与新配置。逐封面组件保存 `coverStyle`、`coverRotation`、`coverFadeStart`、`coverFadeDirection`；样式与旋转只有点击「保存并应用」时才持久化。
- 不修改歌曲、音乐源、歌单、收藏、播放记录或媒体资源缓存。没有数据库 schema 迁移。

## 现有行为保留

内置默认播放页仍使用黑胶；右向左滑动进入独立完整歌词页、下滑返回、睡眠定时、快捷区、播放控制、自由画布编辑、布局导入导出、封面取色和可选背景模糊均保持现有实现。滚动歌词不因为沉浸封面而另起一套系统。

## 实现范围

- `lib/core/player_layout.dart`：逐元素样式/渐隐配置，v4 格式与矩形边界。
- `lib/core/player_layout_store.dart`：切换存储 key，不读旧版。
- `lib/ui/player_cover.dart`：三种视觉渲染。
- `lib/ui/player_layout/layout_renderer.dart`：从元素属性传递样式。
- `lib/ui/player_layout/layout_editor.dart`：三选一、尺寸/渐隐参数与预览。
- `lib/core/appearance.dart`、`lib/ui/settings_page.dart`：移除全局封面开关。
- `lib/ui/lyrics_page.dart` 与迷你播放器：横条 / 歌词页保持圆角缩略图，悬浮按钮固定圆形黑胶。

本次补丁只进行静态改造；实际 Flutter 编译、设备性能、触摸事件与视觉效果须在目标开发机验收，不将源码修改视为已验证通过。
