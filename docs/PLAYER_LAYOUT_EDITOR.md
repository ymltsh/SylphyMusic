# 播放页布局编辑器

入口：正在播放 → 进度条上方「更多」→「编辑播放页」。「更多」只保留音质信息与编辑播放页；完整歌词通过点击歌词区或左滑进入，完整歌词字号在歌词页内调整，播放页菜单不再提供歌词导入。编辑器与播放核心分离，不创建独立播放器。

## 当前设计

播放页不再划分「封面区 / 歌词信息区 / 播放控制区」。打开编辑器时直接载入**当前实际播放页**（系统默认或自定义模板），整页是一张自由画布；保存后看到的构图、字体、颜色、封面形状和歌词预览与编辑器一致。

- 画布比例来自当前设备播放页的实际可用区域（安全区、最大内容宽度 1200 dp；播放页无顶栏），不是固定的 360×640。
- 编辑器使用与播放页相同的浅色 / 深色、封面取色主题、背景、当前曲目封面和当前歌词，不显示示例歌词。
- 唱片 / 方形封面、旋转以及完整 / 迷你歌词字号来自播放页设置，不再作为每个组件的独立属性。
- 完整歌词只有一个页面：在播放页从右向左滑动、点击任意「歌词预览」或菜单「查看完整歌词」都会打开同一个歌词页；该页带返回键、字号菜单和播放控制。
- 页面上的「歌词预览」就是独立于完整歌词页的迷你歌词区。播放页不再显示右下角缩放按钮；需要调整宽高时进入编辑器，选择「歌词预览」组件。
- 选择「歌词预览」后可调整「歌词行距」：1.00～2.50 倍，默认 1.50 倍，实时预览，支持撤销 / 重做并随布局保存、导出和恢复。行距作用于每一行文字，包括长句换行；空间不足时减少相邻句，优先保留当前句。完整歌词页不受影响。
- 从播放页内容区域右向左滑动会打开唯一完整歌词页；点击歌词区也进入同一页。该手势在系统默认与自定义布局中都可用。
- 系统默认布局也是同一套自由画布，进入编辑器不会再出现「播放页是唱片、编辑器却是方形」的状态断裂。

## 使用

1. 从顶部模板菜单选择「沉浸封面」「歌词优先」或已保存的个人模板。首次从系统默认布局进入时，编辑器载入的正是当前页。
2. 直接在全页画布上拖动组件，拖右下角控制点缩放。9 宫格（3×3）和 16 宫格（4×4）是全部辅助线，不再有分区边界。
3. 顶部网格按钮可切换 9 / 16 宫格；吸附开关控制边缘 / 中心是否贴合宫格线。拖动或缩放时显示当前吸附线。
4. 在组件面板添加封面、歌曲标题、歌手 / 专辑、歌词预览、线性进度、组合播放控制、队列、收藏或装饰色块。最多 32 个组件。
5. 面板可调整宽高（封面只有一个「大小」）、透明度、文字对齐、字号（标题 / 歌手）、颜色、封面圆角（仅方形封面）及播放控制参数；可锁定、隐藏或删除。歌词预览使用“迷你歌词字号”，完整歌词使用“完整歌词字号”，迷你字号在编辑器「歌词预览」中调整，完整字号在歌词页内调整，设置也保留独立入口。
6. 顶部眼睛按钮切换交互隔离预览；预览与编辑均不会触发播放或 Seek。退出未保存编辑有放弃提示，最多 80 步撤销 / 重做。
7. 点击勾选「保存并应用」生效。从尚未启用自定义布局的系统默认页进入时，保存会创建一份独立自定义模板；取消或放弃不会改变组件布局；封面样式、旋转、迷你歌词字号和背景开关作为全局外观设置自动保存，面板有明确提示。操作菜单可改名、另存为新模板、恢复默认草稿、使用系统默认布局、导入 / 导出 JSON。最多保存 20 个模板。

手机和宽屏保存的是同一模板的**两套完整画布坐标**，没有区域概念；在宽屏窗口编辑宽屏坐标，在手机编辑竖屏坐标。新添加的组件会同时写入两套坐标作为起点。实际渲染会将封面按短边保持为正方形，所以圆形唱片、选择框和缩放手柄使用同一个边界。

进度条上方固定显示「睡眠定时 / 歌词页 / 收藏 / 更多」四个快捷入口，跟随第一个可见进度条的位置；没有进度条时保留底部入口，避免无法进入编辑器恢复。旧自定义布局与快捷行相交的歌词区会缩短显示范围。编辑器显示同一排图标用于预览，不触发实际播放、收藏或定时操作。

## 组件与样式

- 「专辑封面」：方形时为可调圆角；组件面板内可切换「唱片样式」和「唱片旋转」；唱片样式开启时显示为带黑胶纹路、中心孔和旋转的唱片。编辑预览、播放页、歌词页头图和折叠迷你播放器共用同一个封面组件。
- 「歌词预览」：最多显示 5 句当前歌词，只取每个时间戳的主句；每句可自动换为最多两行，按实际高度减少相邻句数，优先显示完整当前句；完整的原文 / 译文、时间轴跟随、滚动、点击 Seek 和字号都在唯一完整歌词页中。预览是播放页内的迷你歌词控件，在编辑器中调整大小，不是完整歌词页的另一种实现。组件面板内可直接选择迷你歌词字号。颜色提供「默认 / 主题 / 预设色」：「默认」在未设置颜色时随系统深浅使用黑 / 白，「主题」使用主题主色；选择主题或预设色会退出默认模式，随模板保存。
- 「播放控制」：播放 / 暂停按钮可调圆角、宽度（56–96 dp）、高度（48–96 dp）和按钮间距（0–32 dp）；队列入口固定在同一排。播放键默认使用 `primary / onPrimary`，也支持自定义背景色的对比度回退。
- 「进度条」：共享播放页的 Seek 样式和缓冲状态。
- 「歌曲标题 / 歌手」：字号、对齐、颜色和透明度独立。标题按组件高度显示最多两行完整文字，歌手 / 专辑保持单行，超长末尾省略；长按（桌面悬停）查看完整内容。按实际字体和系统文字缩放测量，极矮组件会缩小至一行可完整显示，避免裁切和越界；播放页与编辑器预览共用此规则。歌词字号不再写入组件，完整歌词与迷你歌词各自使用独立全局字号。
- 播放页默认跟随应用浅色 / 深色主题；背景支持封面模糊、主题渐变和纯色。封面模糊是可选层，默认关闭，并遵守设置中的「封面模糊背景」总开关；关闭总开关时，布局里的「封面模糊」选项使用主题 / 纯色底色。编辑器「页面」提供此开关。

## 配置与迁移

- `lib/core/player_layout.dart`：v2 全画布数据模型、校验、内置模板、宽屏坐标、封面正方形边界和 v1 迁移。
- v2 的 `props.lyricLineHeight` 保存迷你歌词行高倍率，旧文件缺失时按 1.50 读取；无需数据库迁移。
- v2 的 `props.lyricFollowSystemColor` 仅用于歌词预览，缺失时按 `true` 读取（按系统深浅取黑 / 白）；选择「主题」或预设色后保存为 `false`，旧模板无需迁移。
- `lib/core/player_layout_store.dart`：通过现有 SQLite settings 原子保存模板与当前选择，串行写入并在数据库关闭前等待完成。数据库 schema 不变，仍使用历史 key `player_layouts_v1`，容器负载版本为 2。
- `lib/ui/player_layout/layout_renderer.dart`：组件注册表和唯一的全画布渲染器；不再包含 PageView 或分区裁切。
- `lib/ui/player_layout/layout_editing.dart`：草稿、80 步撤销 / 重做与 9 / 16 宫格吸附。
- `lib/ui/player_layout/layout_editor.dart`：自由画布编辑、属性面板、预览与文件操作。
- `lib/ui/player_scene.dart`：播放页场景渲染，直接使用已保存的组件布局。
- `lib/ui/player_cover.dart`：播放页、编辑器、歌词页和迷你播放器共用的方形 / 唱片封面。
- `lib/ui/lyrics_page.dart`：唯一完整歌词页面；播放页右向左滑动进入。

### v1 → v2

v1 曾把组件存放在封面 / 信息 / 控制三个纵向区域，并分别保存竖屏 / 宽屏坐标；v2 在读取时按旧区域公式还原参考画布上的实际矩形，再归一化为整页坐标，并为缺失的宽屏坐标生成同样的全画布坐标。旧文件不会被原地覆盖，只有用户保存或选中模板后才写回 v2。v1 的每组件 `circle` / `rotate` 不再迁移：唱片形状和旋转现在统一由外观设置控制，避免同一页出现多种互相矛盾的状态。

导入 JSON 仅包含组件、几何与样式，不保存曲目身份、封面文件路径、音乐源、凭据或 Dart 代码。单文件最多 128 KiB；导入拒绝未知版本、未知组件、重复 ID、越界坐标和不合法参数。导入先进入草稿，保存后才应用。读到损坏或不支持的持久化数据时回退系统布局并提示，原始设置保持到用户显式保存。

验证入口：`test/player_layout_test.dart`、`test/lyrics_preview_test.dart`、`test/appearance_test.dart`、`integration_test/player_layout_test.dart`、`integration_test/ui_refresh_test.dart`。实际平台结果见 [进度](PROGRESS.md)。
