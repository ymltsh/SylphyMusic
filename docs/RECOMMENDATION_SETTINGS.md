# 推荐设置

## 功能分区

- 基础推荐：根据收藏与收听习惯选曲、参考公开热度。关闭个性化会停止新增收听统计，推荐仍可使用。公开热度单独控制联网获取榜单。
- LLM 增强：增强开关、模型连接、辅助／主导选曲、等待时间，以及当前音乐笔友的角色卡和记忆管理。关闭增强时保留配置；连接、角色及记忆管理仍可打开，参与方式和等待时间暂不可改。
- 换新与数据：每日自动换新频率、推荐统计清理。频率以可见选项展示，按本地时间分段，错过不补发，仅影响每日精选。

## 操作与反馈

基础选曲设置立即保存，下次换新时使用；页面显示保存提示，用户可通过“立即更新推荐”一次更新每日精选与专辑，避免每次切换开关都调用模型。更新期间锁定相关操作；失败不撤销已保存设置，允许重试。频率修改只保存节奏设置。

LLM 开启前说明发送数据与第三方费用；开启、关闭或参与方式等模型配置变更沿用现有配置版本通知，使首页重新评估推荐。辅助方式重排基础候选，主导方式从扩展候选选曲，均限定于用户自己的曲库。

“模型连接”直接进入专用页面，复用 API 设置中的地址、模型、系统安全存储密钥和显式连接测试。连接测试在增强关闭时也可主动执行，不会修改增强开关；只使用合成歌曲元数据，可能产生 API 用量。普通推荐请求仍要求开启增强，连接测试继续遵守服务关闭、配置版本变化及网络安全校验。

清除统计需确认，删除累计收听统计与推荐快照；收藏、歌单、角色记忆及来信存档保留。该操作不直接触发模型请求。

窄屏参与方式上下排列，宽屏并排；文字允许换行，页面沿用 Material 3 应用主题。
