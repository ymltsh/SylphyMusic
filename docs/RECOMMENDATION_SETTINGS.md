# 推荐与音乐笔友

从「设置 → 外观与个性化 → 推荐与音乐笔友」进入，也可在设置首页搜索「推荐」或「笔友」。

## 功能分区

- 基础推荐：根据收藏与收听习惯选曲、参考公开热度。关闭个性化会停止新增收听统计，推荐仍可使用。公开热度单独控制联网获取榜单。
- 每日换新：设置刷新频率，或立即更新每日精选和专辑推荐。自动换新按本地时间分段，错过不补发，仅影响每日精选。
- 模型增强：配置模型连接、启用增强、选择辅助或主导选曲并设置等待时间。开启增强后可调整参与方式和等待时间。
- 音乐笔友：管理角色卡、提示词和角色记忆。
- 推荐数据：回看每日推荐文案存档，或清除推荐统计。

## 操作与反馈

基础选曲设置立即保存，下次换新时使用；页面显示保存提示，用户可通过“立即更新推荐”一次更新每日精选与专辑，避免每次切换开关都调用模型。更新期间锁定相关操作；失败不撤销已保存设置，允许重试。频率修改只保存节奏设置。

LLM 开启前说明发送数据与第三方费用；开启、关闭或参与方式等模型配置变更沿用现有配置版本通知，使首页重新评估推荐。辅助方式重排基础候选，主导方式从扩展候选选曲，均限定于用户自己的曲库。

「模型连接」与「设置 → 在线服务 → 模型连接」打开同一个配置页，可编辑接口地址、模型、系统安全存储密钥，并手动测试连接。连接测试在增强关闭时也可主动执行，不会修改增强开关；只使用合成歌曲元数据，可能产生 API 用量。普通推荐请求仍要求开启增强，连接测试继续遵守服务关闭、配置版本变化及网络安全校验。

清除统计需确认，删除累计收听统计与推荐快照；收藏、歌单、角色记忆及来信存档保留。该操作不直接触发模型请求。

参与方式和等待时间使用下拉选择。窄屏或较大字体下，选择器显示在标题与说明的下方。
