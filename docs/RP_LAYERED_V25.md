# 分层长期记忆 v25（SQLite v24）

日记、周记、月记为同一角色长期记忆的三种密度，取代独立 rp_continuity。真实聊天、来信回复和留言形成证据，无人参与的自动推荐信不入队。生成新推荐前最多按需整理三次，缓存读取不整理。

同一本地日合并为一篇日记；日期已满七天的日记可合并进对应自然周的周记，四本成熟周记归纳为月记（四周密度，不强制公历月份）。成功写入上层后才删除被压缩下层；失败保留证据。上下文预算为最近七篇日记、四篇周记、十二篇月记，并限制每篇字数，数据库保留的月记不因上下文预算删除。

删除来源聊天或撤回已整理留言会撤回该角色的派生摘要，从剩余保留证据于新推荐前重建。留言编辑替换其原证据；已整理证据被修改时也撤回摘要。每个角色独立，保留记忆开关和角色隔离。整理状态诊断只记录结果数量，不记录正文、用户名或角色 ID。管理页分组显示三级记忆及状态。

## 一次性迁移

首次运行从 SQLite v23 升到 v24，DROP 并重建旧日记队列、日记及连续记忆表。已有聊天、留言、来信、推荐快照、世界书、角色卡、音乐源、曲库、歌单、收藏、缓存和最近播放身份保留，旧聊天不自动回灌新日记。更早版本仍经过已有迁移清理，之前已删除数据无法恢复。

升级前应备份实际 SQLite 及 WAL / SHM，源码备份不能恢复旧摘要；迁移不是安全擦除外部备份。本轮只应用源码、编译与发布，不启动应用或打开用户数据库。模型整理可能增加费用；编译成功不代表迁移与分层整理已通过设备验收。本说明替代先前文档中四项连续认知的当前设计。
