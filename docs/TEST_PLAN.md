# 风灵音乐：完整功能真实环境验收清单

## P0 — 首次跑通

- [ ] `flutter pub get`、`flutter analyze`、`flutter test` 在指定 Flutter 版本成功
- [ ] Android Debug 构建 + 音频前台服务通知运行
- [ ] Windows 与 Linux Debug 构建、原生 libmpv 动态库随程序正常加载
- [ ] Emby：正确 URL + 密码成功，错误 URL / 错误密码 / HTTPS 证书异常有明确错误
- [ ] Emby：带反向代理前缀的 URL 登录、全量分页索引、封面 ID 与音频时长字段验证
- [ ] OpenSubsonic：Token+Salt 登录、专辑列表分页、歌单 CRUD（仅安全端点）
- [ ] BR1：仅监听 127.0.0.1，不监听 0.0.0.0；无票据返回 403/404
- [ ] 播放：HTTP 200 整曲、206 Range、Seek 到未缓存区域、暂停和恢复、切歌不残留半曲文件
- [ ] 缓存完整入库 SHA-256，崩溃时残片清理，完全缓存后离线播放
- [ ] 歌单增删曲目、复制为云端歌单时仅保留绑定来源，云端回读完全一致

## P0 — 可靠性

- [ ] Android 来电、Duck、永久失焦、耳机拔出/蓝牙断开，恢复逻辑不误自动发声
- [ ] Android 进程真正重启后队列/进度恢复且默认暂停，后台会话重连不断播
- [ ] 歌单缓存任务重启后恢复任务，不续传不完整歌曲的字节
- [ ] 清理单曲/来源/全部缓存时取消匹配任务，其他来源不受影响
- [ ] 连续三首播放失败后停止自动跳过；用户明确点选失败时不自动跳过
- [ ] 服务端并发修改云歌单时合并仅安全追加；其他冲突保留本地操作

## P1 — 数据与极限

- [ ] 5/10 GiB 设备独立预算与自适应磁盘安全余量；磁盘写满中途不会提交 READY
- [ ] P2 下一首仅 2 MiB 接收预算、总临时内存不超过 4 MiB，插队后及时作废旧预取
- [ ] 高解析 FLAC、混合来源切歌、不同采样率、重复歌曲条目、含中文/特殊符号曲名
- [ ] Emby A 与 Emby B 账号同一曲不共用授权或缓存；删除 A 不影响 B
- [ ] 服务器移除曲目仅软删除索引、已缓存歌曲仍可播；显式删除来源清本机数据，不碰服务器文件
- [ ] 断网后编辑云歌单；恢复网络与 Windows 端同时编辑；冲突前保存两版
- [ ] 局部同步出错不错误删除 SQLite 旧库
