# 专辑与歌单封面流

`lib/ui/cover_flow.dart` 提供不依赖第三方库的 Cover Flow 组件，用于专辑和歌单封面的横向浏览。

## 行为

- 中央封面为当前项，两侧按距离缩小、降低不透明度并绕 Y 轴旋转；只构建当前位置附近（距离小于 3.8）的封面，通常不超过 7 项。
- 水平拖动直接驱动同一个 `PageController`，松手后按位置和速度吸附到相邻项；点击中央封面触发 `onActivate`，点击侧边封面先移动到该项。
- 标题、副标题和位置提示固定在底部，调用方通过 `bottomPadding` 为悬浮迷你播放器预留空间。
- 组件不持有数据源，只接收 `itemCount` 与按需封面 / 标题构建器，可继续复用现有 SQL 分批查询和虚拟化，不必一次加载整个曲库。
- 当前选中项、列表 / 封面流选择都只保留在当前会话，不写入设置；重新启动应用回到列表 / 网格。

## 接入

- **音乐库专辑视图**：胶囊筛选栏右侧的图标在列表与 Cover Flow 之间切换。封面流仍按每批 100 行读取 SQLite，只构建可见附近项；点击中央封面进入现有专辑详情。歌曲、艺术家视图和添加歌单选曲不启用。
- **歌单页**：页头图标在歌单网格与歌单 Cover Flow 之间切换。封面取该歌单第一首曲目的封面，没有可用曲目时显示歌单类型图标；点击中央封面进入现有歌单详情。

原补丁在筛选栏追加带文字的 `SegmentedButton`，会改变分类切换时的筛选栏高度，并在 360 dp 手机上被挤出横向滚动区域。当前实现改为与胶囊同高的 40 dp 图标按钮，位置固定在筛选栏右侧；选中时切换图标，Tooltip 提示目标视图。

## 验证

`test/cover_flow_test.dart` 覆盖中央封面点击激活与滑动换页；`integration_test/ui_refresh_test.dart` 覆盖专辑封面流开启、点击进入专辑、切回列表；`integration_test/playlist_refresh_test.dart` 覆盖歌单封面流开启、点击进入歌单、切回网格。实际日志和截图见 [PROGRESS](PROGRESS.md)。
