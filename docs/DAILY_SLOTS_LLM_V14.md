# 每日分时推荐与两阶段 LLM V14

默认按本地日期分成 00–07、08–15、16–23 三个时段。设置 → 外观与个性化 → 推荐设置可调整为 1 / 2 / 3 / 4 / 6 次。启动 / 返回前台时检查当前时段，不后台唤醒、不补发。完整推荐按日期、时段和 LLM 配置复用；手动换一批等待在途自动生成后再新建一轮，结果满足当前时段，不影响已播放队列。专辑不跟随每日次数强制换新。

LLM 先仅选择整数 ID，再只向写信阶段提供选中候选并重映射理由。两阶段都成功、理由有效且歌曲信件非空时才采用；否则保留本地推荐。星光表示实际成功，随快照持久化。API 设置可选 60 / 90 / 120 秒，默认 90，约三分之一用于选曲、其余写信。连接和读取共用阶段截止时间，保持 128 KiB 上限；跨阶段配置变更或服务关闭会丢弃结果。诊断记录阶段及错误码，空理由 / 空信件作为写信失败，不保存原文。

开启 LLM 后，每轮通常产生两次服务请求，默认每日三轮约六次；专辑、手动刷新及配置改变另计，可能收费。连接测试仍用合成元数据校验兼容输出，不触发真实曲库推荐。

SQLite v13→v14 仅增加 recommendation_snapshots.refresh_period、llm_succeeded；旧成功状态参考已归档信件的 origin 恢复，保留所有私人来信与曲库数据。仍保留 System / User 自定义、启动一次每日一言、单按钮导出配置与尾部播放 / 更多操作。
