# 横屏与 PC

设置 → 横屏与 PC 集中管理横屏迷你播放器、键盘快捷键和 Windows 界面字体。

## 迷你播放器

参考用户提供的网易云底栏，宽屏播放器置于 Scaffold 底部，横跨导航侧栏与内容区。左侧为封面、歌曲/歌手及下方收藏和更多操作；中央为模式、上一首、圆形播放/暂停、下一首及歌词入口，下面配细进度条和两端时间；右侧集中倍速、队列、静音和音量。两侧等宽确保中央控制相对整个窗口居中，关闭音量栏不改变中央位置。空间不足时直接切换为单行极简样式。配色使用应用深浅主题与自定义主色，封面形状与旋转仍遵守全局偏好。更多菜单提供收藏、打开播放页、歌词和收起。

底栏使用明确高度约束：宽屏基础高度 84、极简底栏 64 逻辑像素，另加字号放大和底部安全区空间；音量滑块所在行限制为 36，避免 Scaffold 的最大高度被滑块当作自身高度、挤掉主界面。

进度拖动时先预览，松手后执行一次跳转；音量调整合并连续事件并直接控制应用输出，保留静音前音量，静音不改变系统音量。基础音量、速度与播放模式复用原播放协调器及其存储。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| 空格 | 播放/暂停 |
| Ctrl + 左/右 | 上一首/下一首 |
| 左/右 | 后退/前进 5 秒 |
| Ctrl + 上/下 | 应用音量增加/减少 5% |
| M | 静音/恢复 |
| Ctrl + L | 打开播放队列 |

只在应用前台、Windows 或宽度至少 600 的横屏中处理，可在设置关闭。输入框、滑块及弹窗不接管按键；按钮聚焦时保留空格激活行为。播放切换不重复响应长按，错误不抛至键盘分发器。不注册系统级全局快捷键，既有系统媒体键行为保留。

## Windows 字体

支持从本地选择 20 MiB 以内的 TTF/OTF 字体，立即应用于 Flutter 界面并展示中英文字样，可恢复系统默认。字体复制到应用支持目录 desktop_fonts/，记住选择并在启动时加载；缺失或读取失败退回系统字体。仅删除受管副本，不修改原始字体文件。移动端继续使用系统字体，原生 Windows 桌面歌词不使用该界面字体设置。

DesktopPreferences 通过已有 settings 表保存开关和字体文件名，无需升级数据库。字体读写与设置写入串行，disposeAsync 在数据库关闭前等待其 shutdown；文件选择器取消不改变旧字体。主题通过 FontLoader 动态注册的字体族构造。


底栏比例收紧：宽屏封面 52、主播放按钮 44 逻辑像素；歌名独立一行，歌手与收藏/更多合为第二行。中央进度区最大宽度 460，两侧栏等宽限制在 240–320，避免超宽屏将进度条与歌曲信息过度拉伸；按钮图标和间距同步缩小，保留文字缩放适配和有界高度。


## 官方字体按需下载

Windows 字体设置内提供 HarmonyOS Sans 与 MiSans 两个预设入口。安装包与源码只包含目录、官方 URL 和所选原始 Regular 字体的 SHA-256，不包含厂商字体二进制。用户阅读页面许可说明并选择后才联网下载；启动不下载，也不恢复未完成下载。当前字体保存后随启动加载，切换或恢复默认时删除旧的受管字体和随附许可。

来源为用户指定的华为 HarmonyOS-Sans.zip（约 50 MiB）和小米 MiSans.zip（约 218 MiB）。临时包流式落盘，大小上限 300 MiB；后台 isolate 只读取已知字体条目和许可，不按包内路径解压；校验字体摘要后原子保存。HarmonyOS Sans 保留包内 LICENSE.txt；MiSans 同步从官方地址下载许可 PDF。受管字体旁保存原始许可及来源说明，厂商字体不适用项目 MIT。字体页显著标明作者、使用中的字体、独立许可及官网入口。

下载显示进度，可取消；失败保留当前字体，可重新选择重试。退出主动取消网络并排空工作后关闭数据库。移动端保留系统字体。


## 窗口缩放适配

底栏按扣除安全区和内边距后的实际可用宽度分配空间，三栏要求至少 800 逻辑像素，并随系统字号增加预算；两侧等宽，最少 232，确保右侧倍速/队列/音量和中间主要控件均能容纳。中等窗口不再因旧 1050 断点提前进入收缩样式。

空间不足时直接切换单行极简底栏，保留 40 像素封面、歌曲/歌手信息、上一首、播放/暂停、下一首、队列和更多。底栏基础高度 64，不显示进度条、时间和独立音量栏；点击歌曲打开播放页调节进度。更多菜单集中收藏、歌词、播放模式、倍速和音量，模式/倍速显示当前值，音量面板保留滑块及静音；宽屏完整三栏基础高度仍为 84。
