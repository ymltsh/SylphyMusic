# 日记优先记忆重构 v24（SQLite v23）

本次将日记证据和可修订连续认知作为唯一 RP 长期记忆路径。角色状态、世界书与虚构事件继续独立于真实用户经历。聊天、推荐挑选和推荐写作沿用统一上下文入口；连续认知仅保留角色想法、用户确认事实、关系经历及实际未完成约定四项。不再使用碎片 rp_memories、rp_topics 状态机、avoid_repetition 或永久软件话题锁。

打开信件不再产生第二份旧记忆记录。真实保存的聊天和来信回复、新生成的模型来信进入证据队列；新推荐生成前最多整理三批，每批最多八条同会话记录，失败保留证据。管理界面保持双页签，移除旧碎片记忆、话题翻篇列表和第五项避免重复编辑框。

## 一次性数据重置

数据库从 v22 升至 v23。在首次启动的升级事务中清空旧推荐快照及条目、来信、推荐反馈、推荐播放统计、聊天、旧记忆事件、留言、日记队列 / 日记 / 连续认知和已触发角色事件 / 每日抽取记录，并 DROP 旧碎片记忆与话题表。音乐源及凭据、曲库、歌单、收藏、黑名单、缓存、队列、最近播放身份、角色卡、API 配置、自定义世界书、角色场景 / 活动 / 目标和停用记忆选择保留。

应用前的源码备份不包含用户数据库。升级运行前需另备份实际 SQLite 及 WAL / SHM；逻辑删除不能安全擦除旧备份、导出文件或 SQLite 空闲页。本次发布过程不启动应用，不迁移实际用户数据库。

本说明替代早期 RP v21 / v22 / v23 文档中碎片记忆、话题冷却、五项连续认知的当前行为描述；历史文档保留供参考。实际迁移和模型表现仍需用户验收。
